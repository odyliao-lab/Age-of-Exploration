## 1. 診斷：現在的遊戲為什麼無聊

| 環節     | 現況                                         | 問題                                 |
| -------- | -------------------------------------------- | ------------------------------------ |
| 航行     | 點航點 → 看船沿線滑動 → 等抵達               | 玩家沒有操作，等於看進度條           |
| 風與洋流 | 只是速度加減的數字                           | 感受不到，也不需要運用               |
| 港口     | 文字面板＋按鈕（任務板、補給、酒館、造船廠） | 像填表單，沒有「來到異國港口」的感覺 |
| 學習     | 抵達後跳出選擇題                             | 學習和遊玩分離，像考試               |
| 目標     | 任務一條接一條，告訴玩家去哪裡               | 沒有自己決定、自己發現的樂趣         |
| 畫面     | 靜態海圖、小圖示、文字彈窗                   | 沒有動態、場景、人物                 |

根本原因：**把「學地理」做成了「遊戲的外皮包著測驗」**，而不是讓地理知識本身成為玩好遊戲的工具。

## 2. 《大航海時代 2》好玩在哪裡

1. **親手開船**：直接操控船隊在大地圖上航行，風向和船型（橫帆、縱帆）決定能不能逆風前進；每走一天，水和糧食就減少。每一段航程都是自己開出來的。
2. **港口是可以走的城鎮**：主角在街上走動，進酒館、交易所、造船廠、王宮。每個文化圈的街景不同，一進港就有「到了異國」的感覺。
3. **發現物系統**：酒館裡的學者和旅人給線索（「據說在某某港口南方的海岸……」），玩家自己推理位置、開船過去、靠近後調查，發現後回報獲得名聲與獎金。**這就是地理推理，而且是玩家主動想做的事。**
4. **世界地圖逐步展開**：沒去過的地方是空白，地圖隨著航行一點一點補齊。
5. **看得見的遭遇**：海上其他船隊就在地圖上移動，可以迎上去或避開。
6. **貿易的賺錢樂趣**：知道哪裡便宜、哪裡貴，本身就是地理（物產）知識。
7. **夥伴與故事**：在酒館招募航海士，主角有自己的故事線與對手。
8. **自由**：沒有人規定下一步，玩家自己選擇冒險、貿易或探索。

## 3. 新的核心體驗

> **一位年輕的船長兼製圖師，親手駕船、觀星辨位，從酒館的傳聞裡推理出未知之地的位置，把自己親眼見過的世界一筆一筆畫成地圖。**

新的核心循環：

```
酒館聽傳聞（地理線索） → 推理位置、準備補給
        ↑                          ↓
回港回報發現、賣貨、升級船隊 ← 親手駕船（風、洋流、觀星、看岸形）
        ↑                          ↓
      地圖上畫出新海岸線、登錄圖鑑 ← 靠近調查、發現
```

學習不再是「答題」，而是：

- **看懂線索**需要方位、經緯度、地形名詞；
- **開到那裡**需要懂季風、洋流、判讀海岸；
- **找到位置**需要觀星量緯度、比對岸形；
- **賺到錢**需要知道各地物產。

## 4. 新玩法設計（A＋B＋C 全部納入）

### 4.1 親手駕船（B）

- **操作（平板橫向）**：右手拇指在舵輪上左右拖曳轉向；左側按鈕「升帆／收帆／下錨」；雙指縮放地圖。也可以點遠方一點「朝這裡開」，但遇到海岸會停下來，不會自動繞路。
- **風與帆**：畫面上看得見風（風的粒子、旗子、雲的移動）。順風滿帆最快；橫風要調帆；逆風時橫帆船幾乎開不動，縱帆船可以走之字形。
  季風季節的差異（冬季東北、夏季西南）變成真正的策略：什麼時候出航。
- **洋流**：海面上看得到水流紋路，順流加速、逆流變慢。
- **時間**：航行時日子持續推進，水、糧食減少，船員士氣變化，逼玩家做規劃。
- **原本的自動航線**降級為「已走過的航線」才能使用（像大航海 2 的熟悉航線），第一次一定要自己開。

### 4.2 觀星與辨位小遊戲（B）

- **牽星術**（鄭和船隊實際使用的方法）：夜晚仰望星空，用牽星板對準北極星量「幾指」高度，換算成緯度。量得越準，地圖上的位置越精確。
- **看岸形**：接近陸地時，畫面出現海岸與山的剪影，對照針路圖（航海圖冊）上的圖形判斷位置。
- **測深**：近岸放下測深錘，水深與海底泥沙提示離岸遠近。
- 沒有辨位時，船的位置在地圖上是模糊的一圈，越久沒辨位誤差越大（推算航法），讓辨位有實際用處。

### 4.3 地圖逐步繪出（C）

- 開局的海圖只有家鄉附近。航行時，**瞭望範圍內看得見的海岸線會用墨線即時畫上去**，港口與島嶼由玩家命名、標註。
- 地圖本身就是收藏與成就：完成度、正確度，可以和史實的《鄭和航海圖》對照。
- 發現物、航線、風與洋流的觀察會標記在自己的地圖上，成為之後航行的依據。

### 4.4 可以走動的港口城鎮（A）

- 每個港口是一張小地圖。點地面，主角走過去；進入建築物開啟對話場景。
- **建築**：酒館（傳聞、招募夥伴）、市場（買賣）、造船廠、官府或王宮（主線）、學者之家或天妃宮（知識、存檔、祈福）。
- 各文化圈有不同的建築與人物造型：閩南、廣府、占城、爪哇、麻六甲、琉球……（這本身就是文化地理）。
- 人物以對話立繪呈現，取代文字面板。

### 4.5 發現物與傳聞（B＋C）

- 取代現在的「任務板」。酒館、學者、商人會說出傳聞，例如：
  「從泉州出發，沿著海岸往西南走，會經過一座大島和大陸之間的窄海，島上有高山……」
- 玩家自己判斷是哪裡、怎麼去；靠近後按「調查」，出現發現動畫與圖鑑卡，回港回報拿名聲與賞金。
- 現有的 50 張圖鑑卡轉成發現物，並加上傳聞文字。

### 4.6 看得見的海上遭遇（沿用非暴力決議，Q10）

- 海盜、商船、使節船在地圖上移動。可以避開、迎上交涉，或逃跑；逃跑是一段追逐，要運用風向。
- 交涉用貿易品、名聲、當地知識（例如用對方的語言打招呼）。
- 天氣也看得見：遠方的烏雲、霧區、無風帶，可以選擇繞開。

### 4.7 貿易升級

- 每個港口有特產與價格，價差來自地理（例如泉州的瓷器在麻六甲很貴）。
- 行情會隨買賣變動。這是 Q13「輕度貿易」決議的修改，見第 6 節。

### 4.8 夥伴與故事

- 主角是泉州出身的年輕船長，加入鄭和船隊前後的個人故事線。鄭和等歷史人物仍然只以 NPC 出現（Q5）。
- 酒館招募的夥伴各有專長（領航、觀星、通譯、醫師），會在航行中說話、提醒，讓畫面有人味。

### 4.9 畫面與手感（A）

- 海面：波浪與反光、船隻隨浪搖晃、船尾水痕、風的粒子、雲影；日夜變化（夜晚才能觀星）。
- 天氣：暴風雨有雨、閃電與畫面晃動；霧會遮住視野。
- 鏡頭：航行時拉近跟著船；看地圖時拉遠變成自己畫的海圖。
- 回饋：發現時陸地從霧中浮現加上音效；金幣飛入、名聲上升等動畫。
- 美術仍由程式繪製（沒有美術人力），風格見第 6 節的決策。

## 5. 保留與調整的既有系統

| 系統                                 | 處理                                                         |
| ------------------------------------ | ------------------------------------------------------------ |
| 真實地理底圖、陸地判定、季風洋流模型 | **保留**，是新玩法的基礎                                     |
| 船況（補給、士氣、耐久）、船種、船員 | **保留**，改成航行中持續可見                                 |
| 圖鑑 50 張與資料來源                 | **保留**，轉成發現物＋傳聞                                   |
| 任務與問答                           | **縮減**：主線改成故事事件，問答改成「學者之家」的選擇性挑戰 |
| 成就、成長、技能、外觀               | **保留**，技能改成配合新操作（例如觀星更準）                 |
| 錯題回流、今日航程、航海日誌         | **保留**，內容改成發現與觀測紀錄                             |
| 存檔、雲端同步、PWA、部署            | **保留**，存檔需要升級版本                                   |
| 航線規劃（點航點）                   | **改成**熟悉航線的快速航行                                   |

估計既有程式約六成可沿用；主要重寫的是航行操作、港口畫面與畫面表現。

## 6. 擁有者決策（2026-09-29 定案）

| #   | 問題     | 決議                                                                                               |
| --- | -------- | -------------------------------------------------------------------------------------------------- |
| R1  | 美術風格 | **(c) 混合**：航行與世界地圖用古地圖風並加上動態效果；港口城鎮與人物用像素風，致敬《大航海時代 2》 |
| R2  | 自由度   | **(a) 開放世界**：主線故事只是其中一條路，玩家自由選擇探索、貿易或主線                             |
| R3  | 貿易     | **提升**為可以靠貿易賺錢：各港特產、價差、行情隨買賣變動（修改 Q13「輕度貿易」）                   |
| R4  | 海上衝突 | **維持非暴力**（Q10）：避開、交涉、逃跑追逐，以知識與名聲化解                                      |
| R5  | 既有問答 | **保留**為學者之家的選擇性挑戰，錯題回流照常運作                                                   |

**R2 開放世界的配套**（國中生不迷失）：

- 酒館傳聞隨時提供「附近、適合目前能力」的線索，並標出難度；
- 航海日誌列出已知傳聞與主線的下一步，但不強制；
- 夥伴會在航行中提醒補給、季風與附近的可疑地點；
- 海域依 Tier 自然限制：外海需要更大的船、更多補給與更好的辨位能力，而不是用看不見的牆擋住。
