# 「星辰導航者」劇本設計筆記（待討論）

企畫書 3.3 的第 4 個劇本「星辰導航者」（大溪地／夏威夷，玻里尼西亞遠航）還沒有開工。
其他五個劇本都能直接套用現有的系統（港口城鎮、市集買賣、金幣、儀器定位），
但玻里尼西亞的航海文化和這些系統差很多。這份筆記整理需要先決定的問題與建議做法。

## 為什麼不能直接套用

| 現有系統   | 問題                                                                 |
| ---------- | -------------------------------------------------------------------- |
| 金幣與市集 | 玻里尼西亞沒有貨幣，也沒有市集；交換以贈禮、互惠與族群關係為主       |
| 港口城鎮   | 島上是村落與祭祀場（marae），沒有官府、客棧、造船廠這種分工          |
| 觀星定位   | 不量星星的高度，而是記住星星在地平線上升起與落下的方位（星羅盤）     |
| 看岸形     | 大洋中央看不到岸，靠的是湧浪、海鳥、雲底的綠光（潟湖反光）、漂流物   |
| 船         | 雙船體獨木舟（vaka／wa'a），蟹爪帆，由整個家族一起航行、移民         |
| 年代       | 大約西元 1000～1300 年，東玻里尼西亞的大移民時代；缺少精確的文字史料 |

## 建議做法

### 1. 貨幣改成「瑪那」（名望）與禮物

- 劇本設定一個欄位，把畫面上的「金幣」換成「禮物」或「貝殼珍寶」（像現在的劇本地名替換一樣，集中在一個地方）。
- 市集改成「交換禮物」：帶來對方島上沒有的東西（例如塔帕樹皮布、羽毛、玄武岩石斧、甘藷、椰子），換回對方的物產；
  價差仍然來自地理（產地與距離），但文案用「交換」而不是「買賣」。
- 名聲系統可以直接當作「瑪那」使用。

### 2. 新的導航玩法：星羅盤與海上的徵兆

- **星羅盤**：夜裡選一顆正在升起的星星，判斷它在哪個方位升起，用來保持航向（取代量北極星高度）。
  南半球看不到北極星，這正好是很好的地理教材。
- **湧浪**：海面上長長的湧浪方向固定，保持船和湧浪的角度就不會偏航；靠近島嶼時湧浪會被折射、反射。
- **陸地的徵兆**：傍晚往同一方向飛的海鳥（燕鷗、鰹鳥）、雲底的淡綠色（潟湖反光）、雲在島的上空停住不動。
- 這些可以做成類似「看岸形」的小挑戰，答對就縮小位置誤差。

### 3. 地圖與內容

- 新海域：大溪地與社會群島、東加與薩摩亞、夏威夷、奧特亞羅瓦（紐西蘭）、拉帕努伊（復活節島）。
- 島嶼是「村落」而不是港口城鎮：建築可以是首領的大屋、祭祀場（marae）、獨木舟屋、交換的廣場。
- 物產：甘藷（來自南美洲，是玻里尼西亞人曾到達美洲的證據之一）、椰子、麵包樹、芋頭、塔帕樹皮布、羽毛。
- 知識卡：大洋洲的三角（夏威夷—紐西蘭—復活節島）、南十字星、湧浪、信風、珊瑚環礁的形成、
  1976 年霍庫雷阿號（Hōkūle'a）以傳統方法重現遠航。

### 4. 需要注意的地方

- 玻里尼西亞的航海傳統至今仍是活的文化（夏威夷、紐西蘭毛利人等），用詞與描述要尊重，避免把人物當成「原始」的陪襯。
- 歷史人物幾乎沒有可靠的文字記錄：主角、對手、船員都用虛構人物；傳說人物（例如庫佩）只在故事中被提到。
- 1000～1300 年的日期、港口名稱都只能用「大約」：劇本簡介要清楚說明這一點。

2. 星羅盤與海上徵兆的玩法，要不要先做一個小原型試玩？
