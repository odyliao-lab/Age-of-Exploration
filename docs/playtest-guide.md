# 親友試玩說明（第一輪）

> 給試玩者的一頁說明。可以直接複製「給試玩者」段落傳給親友。

## 給試玩者

感謝你幫忙試玩！這是一款用航海冒險學世界地理的網頁遊戲：你是泉州的年輕船長，追隨鄭和寶船的航跡，親手駕船從東海一路航向東南亞、印度洋與東非。

**網址**：https://age-of-exploration.odyliao-pikmin.workers.dev/

**需要的時間**：第一次約 30 分鐘就能體驗主要玩法；完整主線六章約 10 小時以上，玩多少都可以。建議用平板橫向，電腦與手機也可以。

**請這樣玩**：

1. 在「東方寶船」劇本按「出航」，會出現泉州城鎮。點地面走路，走到門口就能進入建築；點路人可以聽他用當地話打招呼、聊生活。
2. 到「官府」接下第一個差事（官府也有商人的運貨委託），到「酒館」聽傳聞（按「記在航海日誌」）。
3. 走到棧橋盡頭的船邊，在「碼頭」補給、出港。
4. 出海後親手掌舵：拖曳右下角舵盤上的紅點，或直接點海面。
   - 舵盤外圈綠色最好開，紅色是頂風會停住；往逆風的方向要走之字形。
   - 左側可以收帆、半帆、滿帆、下錨，也可以暫停或加速。
5. 靠近港口時會出現「入港」按鈕。港口在河口裡面時（例如廣州），畫面會提示入口的方向。
6. 夜晚可以用「牽星術」量北極星的高度定位；白天靠近海岸時，可以「看岸形」定位；隨時可以「測深」量水深、判斷離岸遠近（起霧時特別有用）。糧食不夠時，每天可以「撒網」捕魚，淺海和河口魚比較多。位置誤差太大時，傳聞地點會無法確認。
7. 依傳聞的地理線索找到地方後，靠近按「調查」，再回港到「書院」回報，可以領賞金。
8. 海上會遇到海盜快船（往順風方向逃，或躲進霧裡）、商船（可以打聽消息、買補給、把貨賣給他們）、各國的使節船、鄭和的寶船艦隊（可以補滿淡水糧食）、風暴雲團與海霧（可以繞開；船員會先從長浪、黑雲看出風暴從哪個方向來）。海圖右上角的「風與洋流圖」可以看這個月的風向。
9. 在「市集」買本地特產，運到遠方賣，賺取差價。出航前可以到「書院」看這一帶的季風月曆，挑順風的月份出發；風向不對時，可以在「酒館」住到下個月初等季風轉向。「書院」的學者每天也會出三題小考。
10. 開過一次的航線，之後可以在碼頭選「熟悉航線」自動航行。
11. 有空的話打開「日誌」「圖鑑」「船隊」「船長」看看；「船長 → 外觀」可以換頭像、船旗和船身顏色。
12. 手機或平板可以用瀏覽器的「加入主畫面」安裝；在測試名單裡的人，可以用 Google 登入，換裝置接著玩。

**第二個劇本「季風商人」（新）**：主選單的第二張卡片。你是 1414 年亞丁的年輕阿拉伯商人，開著用椰子纖維縫起來的三角帆船，跟著季風往返阿拉伯海、印度、東非，最後到中國的刺桐（泉州）。港口名稱、船的樣子、城鎮裡的人都換成阿拉伯商人的視角。玩過「東方寶船」的人，可以比較看看兩個劇本的不同。

玩的時候遇到任何卡住、看不懂或覺得無聊的地方，隨手記下來就好。

**玩完請回答這幾題**（直接回覆訊息即可）：

1. 你的年級或年齡？
2. 好玩嗎？（1～5 分）哪裡最有趣、哪裡最無聊？
3. 你學到了什麼地理知識？請舉一個例子。
4. 有沒有卡住、不知道下一步要做什麼的時候？在哪裡？
5. 親手掌舵、看風向走之字形，覺得有趣還是麻煩？傳聞、觀星、看岸形、測深哪個最好玩？
6. 你是用什麼裝置玩的？畫面有沒有跑版或按不到的地方？
7. 還想玩後續的內容嗎？最想去世界上哪個地方？
8. 如果玩了「季風商人」：同一片海，從阿拉伯商人的角度看，有什麼不一樣的感覺？

## 給專案擁有者

- **時間點**：第一輪在第一週切片上線後（現在），第二輪在第 6 週 MVP 完成後。
- **對象**：5～10 位，至少 1～2 位國中生（企畫書 18.5）。
- **紀錄方式**：每位試玩者的回覆整理到 `docs/playtests/round-1.md`，一人一節；
  可行動的問題再開 GitHub Issue，標上 `playtest` 標籤。
- **觀察重點**：
  - 規劃航線是否太難（尤其手機觸控與國小高年級學生）。
  - 問答與知識卡的文字量是否合適。
  - 是否理解「？」目的地要依座標找到。
  - 航行速度（×1 大約 1.2 秒一天）是否太快或太慢。
- **隱私**：不登入時，遊戲不收集任何個人資料，進度只存在試玩者自己的瀏覽器；整理回饋時不要記錄真實姓名。
  - 選擇 Google 登入時，Supabase 會保存 Google 帳號識別碼、信箱與遊戲進度，只用來跨裝置同步。
    未成年試玩者請先徵得家長同意再登入；要刪除資料時，由擁有者在 Supabase 後台刪除該使用者（存檔會一併刪除）。
  - Google 登入目前是 Testing 模式，只有加入測試名單的帳號能登入，名單在 Google Auth Platform → 目標對象。

### Google 登入實機驗收（第 7 週）

自動化測試用模擬的 Supabase 驗證了登入流程、上傳、下載、衝突與使用者隔離；以下需要真實帳號，請在正式站或 preview 各做一次：

1. 電腦 A 未登入先玩一段 → 按「用 Google 登入」→ 用測試帳號 1 登入 → 回到選單顯示「已登入」，網址沒有 `?code=`。
2. Supabase → Table Editor → `saves`：出現一筆，`user_id` 是帳號 1。
3. 手機 B 用帳號 1 登入 → 選單出現「繼續航行」，進度與電腦 A 相同。
4. 手機 B 玩一段、回到選單（或按「船長 → 立即同步」）→ 電腦 A 按「立即同步」→ 繼續航行，看到手機的進度。
5. 衝突：兩台都先同步好，再各自玩一段（其中一台可先離線），之後同步 → 出現「選擇要保留的進度」，選任一份後兩台一致。
6. 隔離：用測試帳號 2 在另一個瀏覽器登入 → 看不到帳號 1 的進度；`saves` 表中帳號 2 只有自己的一筆。
7. 登出後本機進度仍在，可以繼續離線玩。
