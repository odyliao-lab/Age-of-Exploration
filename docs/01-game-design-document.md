## 1. 專案概述

### 1.1 一句話定位

> 「一款讓學生扮演年輕船長，從家鄉港口出發，親手航向並『發現』全世界的地理教育遊戲。」

### 1.2 願景

傳統地理教學中，學生常以背誦方式記住國名、首都、地形名詞，缺乏空間感與情境連結。
本遊戲希望把「地理知識」轉化為「航海時必須用到的能力」：

- 想抵達目的地，就得看懂經緯度與方位。
- 想避開風暴，就得理解季風與洋流。
- 想賺到錢，就得知道哪個地區出產什麼。
- 想解開任務，就得認得海峽、半島、島嶼與河口。

知識不是考題，而是航行的工具；學生在「用」的過程中自然記住。

### 1.3 目標受眾

| 項目 | 預設假設（待定案） |
| --- | --- |
| 主要對象 | 國小高年級～國中學生（約 10～15 歲） |
| 次要對象 | 高中生、對地理有興趣的一般玩家 |
| 使用情境 | 課堂輔助（20～40 分鐘一節）、課後自主學習 |
| 語言 | 繁體中文為主，預留英文介面 |
| 裝置 | 以瀏覽器為主（筆電、平板、教室電腦皆可） |

### 1.4 設計原則

1. **玩法即教學**：每個遊戲機制都要能對應到至少一項地理學習目標，避免「先玩遊戲、再插一段考題」的貼皮設計。
2. **真實世界為底**：地圖、地名、物產、氣候皆採真實資料，冒險元素以「傳說」「軼聞」包裝，不扭曲事實。
3. **低挫折、高回饋**：航行失敗不會「Game Over」，而是損失補給、時間或名聲；重點在讓學生願意再試一次。
4. **短循環可切割**：單一任務可在 5～10 分鐘內完成，方便課堂使用。
5. **教師可掌握**：教師能指派任務、查看學習狀況、對應課綱單元。
6. **文化尊重**：避免殖民、掠奪視角；以「探索、交流、記錄」為主軸描述與各地人民的互動。

| --- | --- | --- |

## 2. 學習設計

### 2.1 學習領域總覽

遊戲內容分為六大知識領域，並依「階段（Tier）」逐步解鎖：

| 領域 | 涵蓋內容 | 遊戲中的對應機制 |
| --- | --- | --- |
| A. 位置與座標 | 經緯度、半球、方位（十六方位）、時區、國際換日線、赤道／回歸線 | 導航輸入、航海圖判讀、時區任務 |
| B. 陸與海的形狀 | 七大洲、五大洋、主要海域、海峽、海灣、半島、島嶼、群島 | 發現系統、海圖填色、路線規劃 |
| C. 地形與河流 | 山脈、高原、平原、沙漠、重要河流與河口三角洲 | 沿岸探索、內陸考察任務 |
| D. 氣候與環境 | 氣候帶、季風、信風、洋流、颱風／颶風、極晝極夜 | 航速與風險計算、季節性航線 |
| E. 國家與城市 | 國家、首都、主要港口城市、旗幟、語言 | 港口解鎖、通行證、外交任務 |
| F. 物產與文化 | 特產作物、礦產、飲食、節慶、建築、世界遺產 | 貿易系統、文化圖鑑、使節任務 |

### 2.2 學習目標對應範例

每一個任務在設計時都需填寫「學習目標卡」，例如：

```
任務：《香料的來源》
領域：F 物產與文化 ＋ B 陸與海的形狀
學習目標：
  1. 能指出馬六甲海峽的位置及其連接的兩個海域。
  2. 能說出至少兩種東南亞特產香料及其產地。
遊戲行為：
  - 玩家需從印度果亞出發，自行規劃航線穿越馬六甲海峽抵達麻六甲。
  - 抵達後在市集辨識「丁香」「肉豆蔻」的產地島嶼（摩鹿加群島）。
評量方式：
  - 航線是否經過正確海峽（自動判定）。
  - 市集問答正確率。
```

### 2.3 學習理論依據

- **情境學習（Situated Learning）**：知識在使用情境中習得，記憶更牢固。
- **間隔重複（Spaced Repetition）**：已學過的地點與知識，會以「回訪任務」「船員問答」的方式在數天後重新出現。
- **鷹架（Scaffolding）**：初期提供完整海圖與指引，隨等級提升逐步移除輔助（例如：先顯示目的地座標→只給方位與距離→只給文字線索）。
- **即時回饋**：每次航線、答題、發現都有立即的視覺與數值回饋。

### 2.4 難度階梯（Tier）

| Tier | 名稱 | 解鎖範圍 | 輔助程度 |
| --- | --- | --- | --- |
| 0 | 見習水手 | 家鄉海域（東亞） | 目的地直接標示於地圖，提示完整 |
| 1 | 沿岸領航員 | 東亞 ＋ 東南亞 | 提供座標，需自行找到位置 |
| 2 | 遠洋航海士 | 印度洋、大洋洲 | 提供方位與距離、國家名稱 |
| 3 | 環球探險家 | 非洲、歐洲、美洲 | 只提供文字線索（地形、特產、文化） |
| 4 | 傳奇船長 | 極地、全球自由航行 | 無輔助；含跨領域綜合任務 |

> 起始區域預設為東亞（以台灣或中國沿海為家鄉港口），與學生生活經驗連結；此設定待討論。

## 3. 核心遊戲循環

```
┌──────────────────────────────────────────────────────────────┐
│                                                              │
│  [港口]  接任務 / 補給 / 交易 / 招募 / 升級                    │
│     │                                                        │
│     ▼                                                        │
│  [海圖]  規劃航線（判讀座標、方位、風向、洋流）                 │
│     │                                                        │
│     ▼                                                        │
│  [航行]  即時／回合制航行、遭遇事件、管理補給與士氣              │
│     │                                                        │
│     ▼                                                        │
│  [抵達]  發現新地點、登錄圖鑑、完成任務、獲得經驗與名聲          │
│     │                                                        │
│     └──────────────► 回到 [港口]，解鎖更遠的海域                │
│                                                              │
└──────────────────────────────────────────────────────────────┘
```

### 3.1 一次遊玩（Session）的節奏

以課堂 30 分鐘為例：

| 時間 | 活動 |
| --- | --- |
| 0～3 分 | 登入、查看今日任務與船員提醒（間隔複習） |
| 3～8 分 | 在港口接任務、補給、簡短對話 |
| 8～20 分 | 規劃航線並航行，途中 1～2 個事件 |
| 20～25 分 | 抵達、探索、圖鑑登錄、任務結算 |
| 25～30 分 | 升級分配、查看成就，儲存進度 |

### 3.2 三種遊玩模式

1. **冒險模式（主線）**：跟隨章節劇情逐步探索世界，適合自主學習。
2. **任務模式（課堂）**：教師指派特定任務包（例如「本週：東南亞海峽」），學生完成即可。
3. **自由航行**：解鎖區域內自由探索、蒐集圖鑑、挑戰紀錄。

## 4. 世界與地圖

### 4.1 地圖基礎

- 使用**真實世界地圖**（Natural Earth 公開資料的 GeoJSON），等距圓柱投影（Plate Carrée）為主，方便經緯度直接對應畫面座標。
- 高階任務可切換至**麥卡托投影**與**地球儀視角**，作為「地圖投影會造成面積扭曲」的教學素材。
- 地圖分層：
  - 海圖層：海域名稱、水深示意、洋流箭頭（可切換）。
  - 政治層：國界、國名、首都（依 Tier 逐步顯示）。
  - 自然層：地形、河流、氣候帶（依 Tier 逐步顯示）。
  - 玩家層：已探索區域（戰爭迷霧）、已發現地點、自訂標記。

### 4.2 戰爭迷霧（Fog of Exploration）

- 未航行過的海域以「古地圖手繪風格」呈現，僅有模糊輪廓與「此處有龍」式的裝飾。
- 航行過的路徑周圍會揭開真實地圖，形成「親手畫出世界地圖」的成就感。
- 揭開比例會計入成就與世界地圖完成度。

### 4.3 海域劃分

全球劃分為約 20 個「海域區（Sea Region）」，作為解鎖與任務分組單位：

| 區域 | 涵蓋 | Tier |
| --- | --- | --- |
| 東海／黃海／日本海 | 台灣、中國沿海、日本、韓國 | 0 |
| 南海 | 越南、菲律賓、婆羅洲 | 1 |
| 麻六甲與爪哇海 | 馬來半島、蘇門答臘、爪哇 | 1 |
| 孟加拉灣 | 印度東岸、緬甸、斯里蘭卡 | 2 |
| 阿拉伯海／波斯灣／紅海 | 印度西岸、阿拉伯半島、東非北部 | 2 |
| 西太平洋與大洋洲 | 澳洲、紐西蘭、太平洋島國 | 2 |
| 東非與馬達加斯加 | 坦尚尼亞、莫三比克、馬達加斯加 | 2 |
| 南非與好望角 | 開普敦、納米比亞 | 3 |
| 幾內亞灣與西非 | 迦納、奈及利亞、塞內加爾 | 3 |
| 地中海 | 南歐、北非、黎凡特 | 3 |
| 北海與波羅的海 | 西歐、北歐 | 3 |
| 北大西洋與加勒比海 | 美國東岸、墨西哥灣、加勒比群島 | 3 |
| 南美東岸 | 巴西、阿根廷 | 3 |
| 南美西岸與麥哲倫海峽 | 秘魯、智利 | 3 |

| 北極海域 | 格陵蘭、北歐北岸、西北航道 | 4 |
| 南冰洋 | 南極半島 | 4 |

### 4.4 港口（節點）

- 全球預計 **80～120 個港口**，分為三級：
  - **主港（Hub）**：有完整功能（任務、市集、造船、學院），每區 1～2 個。
  - **一般港**：補給、部分任務、特產交易。
  - **秘境／地標（Landmark）**：無法停靠，但可「發現」並登錄圖鑑（例如：好望角、直布羅陀巨岩、大堡礁、亞馬遜河口）。
- 每個港口資料包含：所屬國家、現代／歷史名稱、座標、特產、氣候、文化小知識、可接任務。

## 5. 航海系統

### 5.1 航行方式

採用**「規劃 ＋ 半即時執行」**：

1. 在海圖上以航點（Waypoint）方式規劃航線，系統即時顯示預估天數、補給消耗與風險。
2. 按下出航後，船隻沿航線自動前進，玩家可隨時暫停、改道。
3. 途中觸發事件時暫停並進入事件介面。

此設計避免操作門檻，讓學生把注意力放在「規劃時的地理判斷」。

### 5.2 影響航行的地理因素

| 因素 | 效果 | 教學對應 |
| --- | --- | --- |
| 風向／信風／季風 | 順風 +30% 速度、逆風 -30%；季風依月份翻轉 | 大氣環流、季風 |
| 洋流 | 順流加速、逆流減速（例如黑潮、墨西哥灣流） | 洋流分布 |
| 緯度 | 高緯度冬季有結冰與極夜風險 | 氣候帶、極地 |
| 颱風／颶風季 | 特定海域特定月份風暴機率大增 | 熱帶氣旋分布與季節 |
| 海峽／狹窄水道 | 必須經過才能連通兩海域，否則需繞行 | 海峽的戰略與地理意義 |
| 淺灘／珊瑚礁 | 需減速或繞行 | 大堡礁等地形 |

### 5.3 補給與船況

- **淡水**、**糧食**：依船員數與天數消耗，耗盡則士氣下降、航速降低（不會直接失敗）。
- **士氣**：受長途航行、事件與船長「領導」屬性影響；過低時船員會「提議返航」。
- **船體耐久**：風暴與觸礁會損耗，於港口修理。

### 5.4 導航挑戰（核心教學互動）

出航前或抵達前會觸發「導航挑戰」，依 Tier 呈現不同形式：

- **座標定位**：「目的地在北緯 1° 東經 104°，請在地圖上標出。」
- **方位判斷**：「從此處往東南方 800 海里，你會抵達哪個港口？」
- **線索推理**：「這座城市位於世界最長河流的出海口附近，四周是沙漠。」（亞歷山卓／開羅）
- **路線選擇**：給定季節與目的地，選出最省時的航線（考驗季風與洋流知識）。
- **時區換算**：「出發時家鄉是正午，抵達的港口現在幾點？」

## 6. 探索與發現系統

### 6.1 發現物圖鑑（Codex）

每一次「發現」都會登錄到圖鑑，並附上一段 50～100 字的知識卡片：

| 類別 | 範例 | 數量目標（完整版） |
| --- | --- | --- |
| 地理地標 | 好望角、麥哲倫海峽、直布羅陀、巴拿馬地峽 | 60 |
| 島嶼與群島 | 馬達加斯加、加拉巴哥、夏威夷、冰島 | 50 |
| 河流與河口 | 亞馬遜河、尼羅河、長江、萊茵河 | 30 |
| 山脈與高原 | 安地斯山、阿爾卑斯山、青藏高原（沿岸可見或內陸考察） | 25 |
| 動植物 | 企鵝、鯨魚、猴麵包樹、大堡礁珊瑚 | 60 |
| 文化與建築 | 泰姬瑪哈陵、金字塔、馬丘比丘、聖索菲亞大教堂 | 60 |
| 物產 | 香料、絲綢、咖啡、可可、白銀 | 40 |
| 天文與氣候現象 | 極光、極晝、南十字星、信風帶 | 20 |

### 6.2 發現方式

- **航行經過**：船隻經過地標附近自動觸發「瞭望員發現」。
- **港口探索**：在港口進行「城市探索」小遊戲（選擇地點→對話→答題→登錄）。
- **內陸考察**：高階任務可派遣考察隊深入內陸（以文字冒險形式進行），發現山脈、遺跡。
- **船員情報**：具備「博物學家」「翻譯官」等職業的船員會提示附近有可發現物。

### 6.3 世界地圖完成度

- 每個海域區顯示「探索率」（迷霧揭開比例＋圖鑑蒐集率）。
- 全球完成度是長期目標，對應成就與稱號。

## 7. 任務系統

### 7.1 任務類型

| 類型 | 說明 | 教學功能 |
| --- | --- | --- |
| 主線任務 | 章節式劇情，引導玩家由近至遠探索世界 | 依序建構全球空間概念 |
| 區域任務 | 各港口提供，完成可提升該區域名聲並解鎖新港口 | 深化該區域知識 |
| 學院任務 | 由「航海學院」出題的純知識挑戰 | 直接對應課綱單元 |
| 每日／每週任務 | 短時間任務（例如：回訪三個已發現地點） | 間隔重複 |
| 教師指派任務 | 教師從題庫或自訂內容指派 | 課堂進度控制 |
| 隱藏任務 | 由特定發現或組合觸發 | 鼓勵探索 |

### 7.2 主線章節草案

以歷史航線為靈感，但主角為虛構的年輕船長，以「重走歷史航線、解開謎題」為敘事：

| 章節 | 標題 | 靈感來源 | 涵蓋區域 | 核心學習 |
| --- | --- | --- | --- | --- |
| 序章 | 家鄉的海 | — | 東亞 | 基本方位、經緯度、海圖判讀 |
| 第一章 | 香料之路 | 鄭和下西洋 | 東南亞、印度洋 | 季風、海峽、東南亞物產 |
| 第二章 | 繞過非洲之角 | 達伽馬 | 東非、南非、西非 | 非洲地形、好望角、洋流 |
| 第三章 | 地中海的智慧 | 古代腓尼基／威尼斯 | 地中海、歐洲 | 歐洲國家、文明遺產、直布羅陀 |
| 第四章 | 向西的賭注 | 哥倫布 | 大西洋、加勒比海、美洲 | 大西洋信風、美洲地理、時區 |
| 第五章 | 環球一周 | 麥哲倫 | 南美、太平洋、大洋洲 | 麥哲倫海峽、太平洋島國、換日線 |
| 終章 | 極地的呼喚 | 極地探險 | 北極、南極 | 極晝極夜、氣候變遷、全球視野 |

### 7.3 任務結構

```
任務 = {
  id, 標題, 章節/區域, Tier,
  學習目標: [ 領域代碼 + 具體目標 ],
  前置條件: [ 已發現 X / 名聲 ≥ N / 完成任務 Y ],
  步驟: [
    { type: "navigate", target: 港口ID, hint_level: 1..4 },
    { type: "discover", target: 地標ID },
    { type: "quiz", question_set: ... },
    { type: "trade", buy: 物產ID, sell_at: 港口ID },
    { type: "dialogue", npc: ..., branches: ... }
  ],
  獎勵: { 經驗, 金幣, 名聲, 物品, 解鎖 }
}
```

任務以資料檔（JSON／YAML）定義，讓教師或協作者不用改程式就能新增內容。

## 9. 人物成長系統

### 9.1 船長屬性

| 屬性 | 效果 | 提升方式 |
| --- | --- | --- |
| 航海術（Navigation） | 航速、導航挑戰的提示數量 | 完成航行、導航挑戰 |
| 地理學（Geography） | 圖鑑知識卡解鎖深度、線索任務可用提示 | 圖鑑登錄、學院任務 |
| 天文學（Astronomy） | 夜間航行、緯度判斷準確度 | 觀星事件、極地任務 |
| 交涉（Diplomacy） | 交易價格、港口名聲獲得量 | 對話任務、貿易 |
| 領導（Leadership） | 船員士氣、事件成功率 | 事件處理、長途航行 |

- 每次升級獲得屬性點自由分配，讓學生感受到「我在變強」。
- 屬性不設硬性門檻擋任務，只影響「難度與提示」，維持低挫折。

### 9.2 技能樹（三條路線）

| 路線 | 核心技能範例 |
| --- | --- |
| 探險家 | 「鷹眼」：發現範圍 +50%；「地形記憶」：曾去過的地形類型自動辨識 |
| 學者 | 「百科」：知識卡直接顯示延伸內容；「推理」：線索任務可排除一個錯誤選項 |
| 商人 | 「行情」：顯示特產最佳售價港口；「人脈」：新港口初始名聲 +10 |

### 9.3 船員系統

- 船員具備職業（舵手、瞭望員、廚師、博物學家、翻譯官、醫師）。
- 各港口可招募具地方特色的船員（例如：在麻六甲招募的翻譯官熟悉馬來語與東南亞文化，會在該區域提供額外知識與提示）。
- 船員有簡短個人劇情，完成後成為「夥伴」，強化情感連結。

### 9.4 船隻

| 船型 | 特性 | 解鎖 |
| --- | --- | --- |
| 戎克船（Junk） | 起始船，適合近海 | Tier 0 |
| 卡拉維爾（Caravel） | 靈活、逆風表現佳 | Tier 1 |
| 克拉克（Carrack） | 載貨量大、遠洋 | Tier 2 |
| 蓋倫（Galleon） | 高耐久、大型船員編制 | Tier 3 |
| 極地探險船 | 抗冰、極地專用 | Tier 4 |

各船型附帶「船隻小知識」卡片，說明其歷史來源與發明地。

## 10. 冒險與事件系統

### 10.1 隨機事件類型

| 事件 | 觸發條件 | 玩家選擇 | 教學對應 |
| --- | --- | --- | --- |
| 風暴 | 颱風季海域 | 迎風／繞道／下錨等待 | 熱帶氣旋季節與路徑 |
| 無風帶 | 赤道附近 | 等待／划槳／改道 | 赤道無風帶 |
| 海盜遭遇 | 特定海域 | 談判（交涉）／逃離（航海）／答題挑戰（地理學） | 非暴力解決，以知識取勝 |
| 漂流物 | 隨機 | 打撈→獲得圖鑑或線索 | 洋流帶來的物品來源 |
| 觀星之夜 | 晴朗夜晚 | 辨識星座→判斷緯度 | 天文導航 |
| 船員生病 | 長途航行 | 靠岸補給新鮮蔬果 | 壞血病、歷史航海知識 |
| 迷航 | 導航失誤 | 依線索重新定位 | 位置推理 |
| 傳說寶藏 | 蒐集地圖碎片 | 解謎找到地點 | 綜合地理推理 |

### 10.2 海盜與衝突處理原則

- 不出現血腥戰鬥畫面。
- 「衝突」以策略選擇與知識挑戰呈現，例如：海盜船長出題「說出這片海域名稱」，答對可安全離開。
- 失敗僅損失部分貨物或金幣，並可透過後續任務追回。

### 10.3 傳說系統（可選）

以各地民間傳說（例如：北歐海怪、南海龍宮、亞特蘭提斯）設計限時探索事件，
明確標示為「傳說」，並在完成後提供「傳說 vs. 科學事實」的對照知識卡。

## 11. 貿易與經濟

刻意保持**輕量**，目的是教物產分布，而非讓學生沉迷刷錢：

- 每個港口有 3～6 種特產，價格依「距離產地遠近」浮動（近便宜、遠昂貴），直觀呈現「產地」概念。
- 貿易獲利上限設計，避免經濟系統壓過探索。
- 特產卡片包含：產地、用途、歷史（例如：胡椒曾與黃金等價）。
- 金幣用途：補給、修船、招募、購買海圖碎片、船隻升級。

## 12. 知識檢核與適性學習

### 12.1 資料收集

系統記錄每一次導航挑戰、問答、發現的結果，對應到「學習目標代碼」，形成個人知識圖譜。

### 12.2 適性機制

- **錯題回流**：答錯的知識點會在 1 天、3 天、7 天後以不同形式（問答→定位→線索）重新出現。
- **提示等級自動調整**：連續答對則減少提示，連續答錯則增加提示。
- **弱項任務推薦**：港口任務板會優先顯示補強弱項的任務。

### 12.3 學生自我檢視

- 「航海日誌」頁面顯示已掌握／學習中／需加強的知識點，以世界地圖熱區呈現。

## 15. 技術架構建議

> 以下為建議，待討論定案後再細化成技術規格文件。

### 15.1 平台與框架

| 層面 | 建議 | 理由 |
| --- | --- | --- |
| 平台 | Web（PWA） | 教室裝置多元、免安裝、易更新 |
| 語言 | TypeScript | 型別安全、生態成熟 |
| 渲染 | PixiJS（地圖與航行）＋ React（UI） | Pixi 處理大量地圖圖形效能佳；React 適合表單與面板 |
| 地圖資料 | Natural Earth（GeoJSON，公共領域） | 免授權、精度足夠 |
| 地圖投影 | d3-geo | 支援多投影切換 |
| 狀態管理 | Zustand 或 Redux Toolkit | 輕量 |
| 儲存（MVP） | 本地 IndexedDB | 先不需要帳號即可玩 |
| 儲存（正式） | Supabase / Firebase（帳號、班級、進度同步） | 教師端所需 |
| 內容格式 | JSON / YAML 資料檔 ＋ Markdown 知識卡 | 非程式人員也能編輯 |
| 國際化 | i18next | 預留多語 |
| 測試 | Vitest ＋ Playwright | 單元與端對端 |
| 部署 | GitHub Pages（MVP）→ Vercel／Cloudflare Pages | 低成本 |

### 15.2 專案結構草案

```
/
├── docs/                 # 企畫、規格、開發日誌
├── content/              # 遊戲內容資料（非程式）
│   ├── ports/            # 港口資料
│   ├── regions/          # 海域區
│   ├── quests/           # 任務
│   ├── codex/            # 圖鑑知識卡
│   ├── events/           # 事件
│   └── curriculum/       # 課綱對應
├── src/
│   ├── engine/           # 航行、地理計算、事件引擎
│   ├── map/              # 地圖渲染、投影、迷霧
│   ├── ui/               # React 介面
│   ├── learning/         # 知識點追蹤、間隔重複
│   └── data/             # 內容載入與驗證（schema）
├── tools/                # 內容驗證、地圖資料轉換腳本
└── teacher/              # 教師後台（可能為獨立子專案）
```

### 15.3 內容驗證

所有內容資料檔以 JSON Schema 驗證，並在 CI 中檢查：
座標是否在合理範圍、引用的港口／圖鑑 ID 是否存在、每個任務是否至少對應一個學習目標。

## 17. 風險與因應

| 風險 | 影響 | 因應 |
| --- | --- | --- |
| 教學與遊戲比重失衡（太像考題或太像純遊戲） | 學生無感或學不到 | 每個機制需通過「學習目標卡」審核；早期試教驗證 |
| 內容量龐大，製作時間長 | 開發延宕 | 以資料驅動設計，先做工具與範本，內容可眾包 |
| 歷史與文化敏感性 | 爭議 | 採「探索交流」視角，避免殖民敘事；文化內容請教師審閱 |
| 地圖資料授權 | 法律風險 | 僅使用公共領域或 CC 授權資料 |
| 課堂裝置效能不一 | 部分學生卡頓 | 地圖分級細節、低效能模式 |
| 學生資料隱私 | 法規 | MVP 不收集個資；正式版遵循相關法規，最小化資料 |
