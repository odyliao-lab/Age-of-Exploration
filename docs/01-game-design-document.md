## 1. 專案概述

### 1.1 一句話定位

> 「一款讓學生扮演年輕船長，從家鄉港口出發，親手航向並『發現』全世界的地理教育遊戲。」

### 1.2 願景

傳統地理教學中，學生常以背誦方式記住國名、首都、地形名詞，缺乏空間感與情境連結。
本遊戲希望把「地理知識」轉化為「航海時必須用到的能力」：

- 想抵達目的地，就得看懂經緯度與方位。
- 想避開風暴，就得理解季風與洋流。
- 想賺到錢，就得知道哪個地區出產什麼。
- 想解開任務，就得認得海峽、半島、島嶼與河口。

知識不是考題，而是航行的工具；學生在「用」的過程中自然記住。

### 1.3 目標受眾

| 項目 | 定案（Q1、Q2、Q6） |
| --- | --- |
| 設計基準 | **國中學生（12～15 歲）**：文字量、知識深度、任務長度以此為準 |
| 涵蓋對象 | 跨年齡：國小高年級可透過低 Tier 與高提示遊玩；高中生與一般玩家可挑戰高 Tier 與無提示模式 |
| 使用情境 | **自學為主**：不需教師介入即可完整遊玩；課堂使用為次要情境 |
| 語言 | 繁體中文為主，預留英文介面 |
| 裝置 | 純網頁 PWA，筆電、平板、手機瀏覽器皆可 |

自學為主帶來的設計要求：

- 遊戲本身必須提供足夠的**目標感與引導**（劇本、每日任務、進度視覺化），不能依賴教師指派。
- 沒有帳號也能立即開始遊玩，進度存於本機；帳號同步為選配。
- 學習成效的回饋要直接給學生看（航海日誌、知識地圖），而非只給教師報表。

### 1.4 設計原則

1. **玩法即教學**：每個遊戲機制都要能對應到至少一項地理學習目標，避免「先玩遊戲、再插一段考題」的貼皮設計。
2. **真實世界為底**：地圖、地名、物產、氣候皆採真實資料，冒險元素以「傳說」「軼聞」包裝，不扭曲事實。
3. **低挫折、高回饋**：航行失敗不會「Game Over」，而是損失補給、時間或名聲；重點在讓學生願意再試一次。
4. **短循環可切割**：單一任務可在 5～10 分鐘內完成，方便課堂使用。
5. **自學可成立**：學生獨自遊玩也能持續獲得目標、回饋與進步感；教師工具為加值而非前提。
6. **文化尊重**：避免殖民、掠奪視角；以「探索、交流、記錄」為主軸描述與各地人民的互動。

## 2. 學習設計

### 2.1 學習領域總覽

知識範圍採**通用世界地理**（Q3），不綁定特定國家的課綱；內容以「全球公民應具備的世界空間概念」為準，
並以標籤方式預留日後對應各地課綱的可能。遊戲內容分為六大知識領域，依「階段（Tier）」逐步解鎖：

| 領域 | 涵蓋內容 | 遊戲中的對應機制 |
| --- | --- | --- |
| A. 位置與座標 | 經緯度、半球、方位（十六方位）、時區、國際換日線、赤道／回歸線 | 導航輸入、航海圖判讀、時區任務 |
| B. 陸與海的形狀 | 七大洲、五大洋、主要海域、海峽、海灣、半島、島嶼、群島 | 發現系統、海圖填色、路線規劃 |
| C. 地形與河流 | 山脈、高原、平原、沙漠、重要河流與河口三角洲 | 沿岸探索、內陸考察任務 |
| D. 氣候與環境 | 氣候帶、季風、信風、洋流、颱風／颶風、極晝極夜 | 航速與風險計算、季節性航線 |
| E. 國家與城市 | 國家、首都、主要港口城市、旗幟、語言 | 港口解鎖、通行證、外交任務 |
| F. 物產與文化 | 特產作物、礦產、飲食、節慶、建築、世界遺產 | 貿易系統、文化圖鑑、使節任務 |

### 2.2 學習目標對應範例

每一個任務在設計時都需填寫「學習目標卡」，例如：

```
任務：《香料的來源》
領域：F 物產與文化 ＋ B 陸與海的形狀
學習目標：
  1. 能指出馬六甲海峽的位置及其連接的兩個海域。
  2. 能說出至少兩種東南亞特產香料及其產地。
遊戲行為：
  - 玩家需從印度果亞出發，自行規劃航線穿越馬六甲海峽抵達麻六甲。
  - 抵達後在市集辨識「丁香」「肉豆蔻」的產地島嶼（摩鹿加群島）。
評量方式：
  - 航線是否經過正確海峽（自動判定）。
  - 市集問答正確率。
```

### 2.3 學習理論依據

- **情境學習（Situated Learning）**：知識在使用情境中習得，記憶更牢固。
- **間隔重複（Spaced Repetition）**：已學過的地點與知識，會以「回訪任務」「船員問答」的方式在數天後重新出現。
- **鷹架（Scaffolding）**：初期提供完整海圖與指引，隨等級提升逐步移除輔助（例如：先顯示目的地座標→只給方位與距離→只給文字線索）。
- **即時回饋**：每次航線、答題、發現都有立即的視覺與數值回饋。

### 2.4 難度階梯（Tier）

Tier 決定「輔助程度」與「可航行範圍」。由於採多劇本模式（見第 3.3 節），
**解鎖範圍不再固定為某個地區，而是以該劇本的家鄉海域為圓心，逐圈向外擴展**：

| Tier | 名稱 | 解鎖範圍（相對於劇本家鄉） | 輔助程度 |
| --- | --- | --- | --- |
| 0 | 見習水手 | 家鄉海域區 | 目的地直接標示於地圖，提示完整 |
| 1 | 沿岸領航員 | 家鄉 ＋ 相鄰海域區 | 提供座標，需自行找到位置 |
| 2 | 遠洋航海士 | 同一大洋範圍內 | 提供方位與距離、國家名稱 |
| 3 | 環球探險家 | 跨大洋，抵達其他大洲 | 只提供文字線索（地形、特產、文化） |
| 4 | 傳奇船長 | 極地、全球自由航行 | 無輔助；含跨領域綜合任務 |

- 每個劇本在資料檔中定義自己的 Tier→海域區對照表。
- 同一名玩家在不同劇本中的 Tier 各自獨立，但**圖鑑與知識掌握度跨劇本共用**，
  避免重複學習同一知識點；已掌握的知識在新劇本中會以「複習」而非「初學」的形式出現。
- 跨年齡設計（Q1）：玩家可在設定中選擇「輔助偏好」（多提示／標準／無提示），
  在 Tier 之上再做一層調整，讓國小生與高中生都能找到合適難度。

## 3. 核心遊戲循環

```
┌──────────────────────────────────────────────────────────────┐
│                                                              │
│  [港口]  接任務 / 補給 / 交易 / 招募 / 升級                    │
│     │                                                        │
│     ▼                                                        │
│  [海圖]  規劃航線（判讀座標、方位、風向、洋流）                 │
│     │                                                        │
│     ▼                                                        │
│  [航行]  即時／回合制航行、遭遇事件、管理補給與士氣              │
│     │                                                        │
│     ▼                                                        │
│  [抵達]  發現新地點、登錄圖鑑、完成任務、獲得經驗與名聲          │
│     │                                                        │
│     └──────────────► 回到 [港口]，解鎖更遠的海域                │
│                                                              │
└──────────────────────────────────────────────────────────────┘
```

### 3.1 一次遊玩（Session）的節奏

以課堂 30 分鐘為例：

| 時間 | 活動 |
| --- | --- |
| 0～3 分 | 登入、查看今日任務與船員提醒（間隔複習） |
| 3～8 分 | 在港口接任務、補給、簡短對話 |
| 8～20 分 | 規劃航線並航行，途中 1～2 個事件 |
| 20～25 分 | 抵達、探索、圖鑑登錄、任務結算 |
| 25～30 分 | 升級分配、查看成就，儲存進度 |

### 3.2 三種遊玩模式

1. **劇本模式（主線）**：選擇一個劇本，跟隨章節劇情從該劇本的家鄉港口逐步探索世界。這是自學的主要入口。
2. **自由航行**：在任一已通關劇本解鎖的區域自由探索、蒐集圖鑑、挑戰紀錄。
3. **任務包模式**：以「任務包」為單位的短程遊玩（例如「世界海峽巡禮」「非洲河流」）。
   自學者可自行挑選，教師端上線後也可用來指派。

### 3.3 多劇本模式（Q4 決議）

玩家不再只從單一地區出發，而是從**多個劇本**中選擇，每個劇本代表一段不同起點、不同文化視角的航海旅程。
劇本共用同一張世界地圖與同一套圖鑑，但各有：

- **家鄉港口與家鄉海域區**（決定 Tier 擴展的圓心）。
- **歷史背景與靈感航線**（真實歷史，Q5 混合制，見 7.2）。
- **章節劇情、專屬 NPC 與船員**。
- **起始船型與起始物產**（反映該文化的造船與貿易特色）。

初版劇本清單草案（數量與順序待討論，見決策清單 Q26～Q28）：

| 劇本 | 家鄉港口 | 歷史靈感 | 主要探索方向 | 文化視角 |
| --- | --- | --- | --- | --- |
| 東方寶船 | 泉州／南京 | 鄭和下西洋（15 世紀） | 東南亞 → 印度洋 → 東非 | 明朝中國 |
| 香料之海 | 麻六甲 | 馬來與南島航海傳統 | 東南亞群島 → 大洋洲 → 印度洋 | 東南亞海洋民族 |
| 季風商人 | 荷姆茲／亞丁 | 阿拉伯印度洋貿易網（辛巴達傳說） | 阿拉伯海 → 東非 → 印度 → 東南亞 | 伊斯蘭世界 |
| 航向未知 | 里斯本 | 亨利王子、達伽馬、麥哲倫 | 西非 → 好望角 → 印度 → 環球 | 伊比利半島 |
| 向西的賭注 | 帕洛斯／塞維亞 | 哥倫布、大西洋航線 | 加那利 → 加勒比 → 美洲 | 西班牙 |
| 地中海之心 | 威尼斯 | 威尼斯商人、馬可波羅 | 地中海 → 黎凡特 → 黑海 → 絲路東端 | 義大利城邦 |
| 星辰導航者 | 大溪地／夏威夷 | 玻里尼西亞遠航 | 太平洋群島 → 紐西蘭 → 復活節島 | 玻里尼西亞 |
| 北方長船 | 卑爾根 | 維京航海 | 北海 → 冰島 → 格陵蘭 → 北美 | 北歐 |

劇本設計原則：

1. **每個劇本都是完整的教學路徑**：通關一個劇本應能覆蓋六大領域的基礎知識。
2. **不同劇本覆蓋不同區域深度**：全部劇本合起來才覆蓋整個地球；鼓勵玩家多玩幾個劇本。
3. **視角多元**：避免只從歐洲「發現」世界的單一敘事；每個文化都是自己旅程的主角。
4. **劇本間可互相引用**：例如在「航向未知」抵達卡利卡特時，可遇見「東方寶船」劇本的 NPC，形成世界觀連結。
5. **推薦順序但不強制**：首次遊玩會依玩家所在地推薦一個劇本，但所有劇本一開始就可選。
6. **資料驅動**：劇本以資料檔定義（家鄉、Tier 對照、章節、NPC），新增劇本不需改程式。

## 4. 世界與地圖

### 4.1 地圖基礎

- 使用**真實世界地圖**（Natural Earth 公開資料的 GeoJSON），等距圓柱投影（Plate Carrée）為主，方便經緯度直接對應畫面座標。
- 高階任務可切換至**麥卡托投影**與**地球儀視角**，作為「地圖投影會造成面積扭曲」的教學素材。
- 地圖分層：
  - 海圖層：海域名稱、水深示意、洋流箭頭（可切換）。
  - 政治層：國界、國名、首都（依 Tier 逐步顯示）。
  - 自然層：地形、河流、氣候帶（依 Tier 逐步顯示）。
  - 玩家層：已探索區域（戰爭迷霧）、已發現地點、自訂標記。

### 4.2 戰爭迷霧（Fog of Exploration）

- 未航行過的海域以「古地圖手繪風格」呈現，僅有模糊輪廓與「此處有龍」式的裝飾。
- 航行過的路徑周圍會揭開真實地圖，形成「親手畫出世界地圖」的成就感。
- 揭開比例會計入成就與世界地圖完成度。

### 4.3 海域劃分

全球劃分為約 20 個「海域區（Sea Region）」，作為解鎖與任務分組單位。
海域區本身**不帶固定 Tier**；每個劇本以自己的家鄉為圓心指定各海域區的 Tier。
下表以「東方寶船」與「航向未知」兩個劇本為例，說明同一海域區在不同劇本中的階段差異：

| 區域 | 涵蓋 | 東方寶船 | 航向未知 |
| --- | --- | --- | --- |
| 東海／黃海／日本海 | 台灣、中國沿海、日本、韓國 | 0 | 3 |
| 南海 | 越南、菲律賓、婆羅洲 | 1 | 3 |
| 麻六甲與爪哇海 | 馬來半島、蘇門答臘、爪哇 | 1 | 3 |
| 孟加拉灣 | 印度東岸、緬甸、斯里蘭卡 | 2 | 2 |
| 阿拉伯海／波斯灣／紅海 | 印度西岸、阿拉伯半島、東非北部 | 2 | 2 |
| 西太平洋與大洋洲 | 澳洲、紐西蘭、太平洋島國 | 2 | 3 |
| 東非與馬達加斯加 | 坦尚尼亞、莫三比克、馬達加斯加 | 2 | 2 |
| 南非與好望角 | 開普敦、納米比亞 | 3 | 1 |
| 幾內亞灣與西非 | 迦納、奈及利亞、塞內加爾 | 3 | 1 |
| 地中海 | 南歐、北非、黎凡特 | 3 | 1 |
| 北海與波羅的海 | 西歐、北歐 | 3 | 1 |

| 南美東岸 | 巴西、阿根廷 | 3 | 2 |

| 南冰洋 | 南極半島 | 4 | 4 |

### 4.4 港口（節點）

- 全球預計 **80～120 個港口**，分為三級：
  - **主港（Hub）**：有完整功能（任務、市集、造船、學院），每區 1～2 個。
  - **一般港**：補給、部分任務、特產交易。
  - **秘境／地標（Landmark）**：無法停靠，但可「發現」並登錄圖鑑（例如：好望角、直布羅陀巨岩、大堡礁、亞馬遜河口）。
- 每個港口資料包含：所屬國家、現代／歷史名稱、座標、特產、氣候、文化小知識、可接任務。

## 5. 航海系統

### 5.1 航行方式

採用**「規劃 ＋ 半即時執行」**：

1. 在海圖上以航點（Waypoint）方式規劃航線，系統即時顯示預估天數、補給消耗與風險。
2. 按下出航後，船隻沿航線自動前進，玩家可隨時暫停、改道。
3. 途中觸發事件時暫停並進入事件介面。

此設計避免操作門檻，讓學生把注意力放在「規劃時的地理判斷」。

### 5.2 影響航行的地理因素

| 因素 | 效果 | 教學對應 |
| --- | --- | --- |
| 風向／信風／季風 | 順風 +30% 速度、逆風 -30%；季風依月份翻轉 | 大氣環流、季風 |
| 洋流 | 順流加速、逆流減速（例如黑潮、墨西哥灣流） | 洋流分布 |
| 緯度 | 高緯度冬季有結冰與極夜風險 | 氣候帶、極地 |
| 颱風／颶風季 | 特定海域特定月份風暴機率大增 | 熱帶氣旋分布與季節 |
| 海峽／狹窄水道 | 必須經過才能連通兩海域，否則需繞行 | 海峽的戰略與地理意義 |
| 淺灘／珊瑚礁 | 需減速或繞行 | 大堡礁等地形 |

### 5.3 補給與船況

- **淡水**、**糧食**：依船員數與天數消耗，耗盡則士氣下降、航速降低（不會直接失敗）。
- **士氣**：受長途航行、事件與船長「領導」屬性影響；過低時船員會「提議返航」。
- **船體耐久**：風暴與觸礁會損耗，於港口修理。

### 5.4 導航挑戰（核心教學互動）

出航前或抵達前會觸發「導航挑戰」，依 Tier 呈現不同形式：

- **座標定位**：「目的地在北緯 1° 東經 104°，請在地圖上標出。」
- **方位判斷**：「從此處往東南方 800 海里，你會抵達哪個港口？」
- **線索推理**：「這座城市位於世界最長河流的出海口附近，四周是沙漠。」（亞歷山卓／開羅）
- **路線選擇**：給定季節與目的地，選出最省時的航線（考驗季風與洋流知識）。
- **時區換算**：「出發時家鄉是正午，抵達的港口現在幾點？」

## 7. 任務系統

### 7.1 任務類型

| 類型 | 說明 | 教學功能 |
| --- | --- | --- |
| 主線任務 | 章節式劇情，引導玩家由近至遠探索世界 | 依序建構全球空間概念 |
| 區域任務 | 各港口提供，完成可提升該區域名聲並解鎖新港口 | 深化該區域知識 |
| 學院任務 | 由「航海學院」出題的純知識挑戰 | 直接對應課綱單元 |
| 每日／每週任務 | 短時間任務（例如：回訪三個已發現地點） | 間隔重複 |
| 任務包 | 主題式任務組合，自學者自選；後期教師端可指派 | 主題複習、課堂進度控制 |
| 隱藏任務 | 由特定發現或組合觸發 | 鼓勵探索 |

### 7.2 劇本章節設計（Q4、Q5 決議）

每個劇本包含 **5～7 個章節**，結構固定為「序章（家鄉）→ 逐圈外擴 → 終章（跨洋或極地）」。
歷史真實性採**混合制**（Q5）：

- **地圖、地名、物產、氣候、航線**：真實。
- **歷史事件與人物**：真實，作為劇本背景與 NPC（例如鄭和、達伽馬、麥哲倫、伊本·巴圖塔會以導師、雇主或同行者身分出現），
  並附「歷史小知識」卡片說明史實與遊戲改編之處。
- **玩家船長**：虛構角色，避免讓學生「扮演」真實歷史人物時產生史實混淆，也讓成長系統與劇情選擇不受史實束縛。
- **傳說與奇幻元素**：允許，但明確標示為傳說並附科學對照（見 10.3）。

以「東方寶船」劇本為例：

| 章節 | 標題 | Tier | 涵蓋區域 | 歷史背景 | 核心學習 |
| --- | --- | --- | --- | --- | --- |
| 序章 | 泉州的少年 | 0 | 東海、南海北部 | 明初海禁與朝貢貿易 | 方位、經緯度、海圖判讀 |
| 第一章 | 占城與麻六甲 | 1 | 南海、麻六甲 | 鄭和首航（1405） | 季風、海峽、東南亞物產 |
| 第二章 | 錫蘭與古里 | 2 | 孟加拉灣、阿拉伯海 | 印度洋貿易網 | 印度次大陸、洋流 |
| 第三章 | 荷姆茲與麥加 | 2 | 波斯灣、紅海 | 伊斯蘭世界的商路 | 阿拉伯半島、沙漠氣候 |
| 第四章 | 麒麟之國 | 3 | 東非 | 鄭和抵達木骨都束、麻林 | 非洲東岸、長頸鹿與物產 |
| 終章 | 海的盡頭 | 3～4 | 好望角以南（虛構延伸） | 「若寶船繼續南行」的假設性冒險 | 綜合推理、南半球 |

其他劇本的章節草案於劇本定案（Q26～Q28）後補上。

### 7.3 任務結構

```
任務 = {
  id, 標題, 章節/區域, Tier,
  學習目標: [ 領域代碼 + 具體目標 ],
  前置條件: [ 已發現 X / 名聲 ≥ N / 完成任務 Y ],
  步驟: [
    { type: "navigate", target: 港口ID, hint_level: 1..4 },
    { type: "discover", target: 地標ID },
    { type: "quiz", question_set: ... },
    { type: "trade", buy: 物產ID, sell_at: 港口ID },
    { type: "dialogue", npc: ..., branches: ... }
  ],
  獎勵: { 經驗, 金幣, 名聲, 物品, 解鎖 }
}
```

任務以資料檔（JSON／YAML）定義，讓教師或協作者不用改程式就能新增內容。

## 10. 冒險與事件系統

### 10.1 隨機事件類型

| 事件 | 觸發條件 | 玩家選擇 | 教學對應 |

### 10.2 海盜與衝突處理原則

- 不出現血腥戰鬥畫面。
- 「衝突」以策略選擇與知識挑戰呈現，例如：海盜船長出題「說出這片海域名稱」，答對可安全離開。
- 失敗僅損失部分貨物或金幣，並可透過後續任務追回。

### 10.3 傳說系統（可選）

以各地民間傳說（例如：北歐海怪、南海龍宮、亞特蘭提斯）設計限時探索事件，
明確標示為「傳說」，並在完成後提供「傳說 vs. 科學事實」的對照知識卡。

## 11. 貿易與經濟

刻意保持**輕量**，目的是教物產分布，而非讓學生沉迷刷錢：

- 每個港口有 3～6 種特產，價格依「距離產地遠近」浮動（近便宜、遠昂貴），直觀呈現「產地」概念。
- 貿易獲利上限設計，避免經濟系統壓過探索。
- 特產卡片包含：產地、用途、歷史（例如：胡椒曾與黃金等價）。
- 金幣用途：補給、修船、招募、購買海圖碎片、船隻升級。

## 12. 知識檢核與適性學習

### 12.1 資料收集

系統記錄每一次導航挑戰、問答、發現的結果，對應到「學習目標代碼」，形成個人知識圖譜。

### 12.2 適性機制

- **錯題回流**：答錯的知識點會在 1 天、3 天、7 天後以不同形式（問答→定位→線索）重新出現。
- **提示等級自動調整**：連續答對則減少提示，連續答錯則增加提示。
- **弱項任務推薦**：港口任務板會優先顯示補強弱項的任務。

### 12.3 學生自我檢視（自學為主的核心介面）

- 「航海日誌」頁面顯示已掌握／學習中／需加強的知識點，以世界地圖熱區呈現。
- 「今日航程」：每次登入提供 3 個短目標（複習、探索、劇本推進各一），10～15 分鐘可完成。
- 連續登入與週目標僅作正向回饋，不設懲罰。
- 知識掌握度跨劇本共用，玩家可在日誌中看到「哪些劇本能補強我的弱項」。

1. 世界海圖（主畫面）
2. 港口畫面（任務板、市集、酒館／招募、造船廠、學院）
3. 航行畫面（船隻、天氣、補給條、事件彈窗）
4. 圖鑑
5. 船長／船員／船隻面板
6. 航海日誌（學習紀錄）
7. 成就與稱號
8. 教師後台（獨立網頁）

### 14.3 無障礙與課堂考量

- 支援鍵盤與觸控操作。
- 字體可放大、色盲友善的地圖配色。
- 文字可搭配語音朗讀（可選，後期）。

## 15. 技術架構建議

> 以下為建議，待討論定案後再細化成技術規格文件。

### 15.1 平台與框架

| 層面 | 建議 | 理由 |
| --- | --- | --- |
| 平台 | Web（PWA），**已定案（Q6）** | 免安裝、易更新、可加入主畫面離線遊玩 |
| 語言 | TypeScript | 型別安全、生態成熟 |
| 渲染 | PixiJS（地圖與航行）＋ React（UI） | Pixi 處理大量地圖圖形效能佳；React 適合表單與面板 |
| 地圖資料 | Natural Earth（GeoJSON，公共領域） | 免授權、精度足夠 |
| 地圖投影 | d3-geo | 支援多投影切換 |
| 狀態管理 | Zustand 或 Redux Toolkit | 輕量 |
| 儲存（MVP） | 本地 IndexedDB ＋ 匯出／匯入存檔 | 自學為主，免帳號即可玩 |
| 儲存（正式） | Supabase / Firebase（選配帳號、跨裝置同步） | 多裝置與後期教師端所需 |
| 內容格式 | JSON / YAML 資料檔 ＋ Markdown 知識卡 | 非程式人員也能編輯 |
| 國際化 | i18next | 預留多語 |
| 測試 | Vitest ＋ Playwright | 單元與端對端 |
| 部署 | GitHub Pages（MVP）→ Vercel／Cloudflare Pages | 低成本 |

### 15.2 專案結構草案

```
/
├── docs/                 # 企畫、規格、開發日誌
├── content/              # 遊戲內容資料（非程式）
│   ├── scenarios/        # 劇本（家鄉、Tier 對照、章節、NPC）
│   ├── ports/            # 港口資料
│   ├── regions/          # 海域區
│   ├── quests/           # 任務
│   ├── codex/            # 圖鑑知識卡
│   ├── events/           # 事件
│   └── curriculum/       # 課綱對應
├── src/
│   ├── engine/           # 航行、地理計算、事件引擎
│   ├── map/              # 地圖渲染、投影、迷霧
│   ├── ui/               # React 介面
│   ├── learning/         # 知識點追蹤、間隔重複
│   └── data/             # 內容載入與驗證（schema）
├── tools/                # 內容驗證、地圖資料轉換腳本
└── teacher/              # 教師後台（可能為獨立子專案）
```

### 15.3 內容驗證

所有內容資料檔以 JSON Schema 驗證，並在 CI 中檢查：
座標是否在合理範圍、引用的港口／圖鑑 ID 是否存在、每個任務是否至少對應一個學習目標。

### 16.1 MVP（最小可玩版本）範圍

目標：驗證「核心循環 ＋ 教學效果」，不追求內容量。

| 項目 | MVP 範圍 |
| --- | --- |
| 劇本框架 | 完整實作（劇本選單、家鄉、Tier 對照、章節），但**只填充 1 個劇本** |
| 首個劇本 | 建議「東方寶船」（待定，Q26）：序章 ＋ 第一章（Tier 0～1） |
| 區域 | 該劇本家鄉 ＋ 相鄰海域區 |

| 任務 | 15～20 個 |
| 圖鑑 | 約 40 項 |
| 事件 | 5 種 |
| 人物成長 | 5 屬性、升級、1 艘可升級船、3 名船員 |

## 17. 風險與因應

| 風險 | 影響 | 因應 |
| --- | --- | --- |
| 教學與遊戲比重失衡（太像考題或太像純遊戲） | 學生無感或學不到 | 每個機制需通過「學習目標卡」審核；早期試教驗證 |
| 內容量龐大，製作時間長 | 開發延宕 | 以資料驅動設計，先做工具與範本，內容可眾包 |
| 歷史與文化敏感性 | 爭議 | 採「探索交流」視角，避免殖民敘事；文化內容請教師審閱 |
| 地圖資料授權 | 法律風險 | 僅使用公共領域或 CC 授權資料 |
| 課堂裝置效能不一 | 部分學生卡頓 | 地圖分級細節、低效能模式 |
| 學生資料隱私 | 法規 | MVP 不收集個資；正式版遵循相關法規，最小化資料 |

## 18. 名詞表

| 名詞 | 說明 |
| --- | --- |
| Tier | 難度／解鎖階段，0～4 |
| 海域區（Sea Region） | 全球海域的分組單位，用於解鎖與任務分類 |
| 劇本（Scenario） | 一段以特定家鄉港口與歷史背景出發的完整旅程，含章節、NPC 與 Tier 對照 |
| 港口（Port） | 可停靠並互動的地圖節點 |
| 地標（Landmark） | 不可停靠但可發現的地理／文化物件 |
| 圖鑑（Codex） | 所有發現物與知識卡的集合 |
| 學習目標卡 | 每個任務必附的教學目標與評量說明 |
| 導航挑戰 | 出航或抵達時的地理判讀互動 |
| 迷霧 | 未探索區域的視覺遮罩 |
